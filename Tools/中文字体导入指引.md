# 中文字体 BLOCKER 修复指引（一键检查清单）

> 现状：项目 UI（按钮、弹窗、飘字、提示）全部使用 `TextMeshPro`，但工程内没有**中文字体 SDF**。
> TMP 英文文本的默认字体是 `LiberationSans SDF`，**不含中文字形** → 所有中文会显示为「口口口」（豆腐块）。
> 本清单可在 5 分钟内修复。若任何一步不满足，中文就会继续显示为方框。

---

## 0. 为什么必须做

| 可见位置 | 用途 | 当前状态 |
|---|---|---|
| 顶部标题「2048 浣熊」、分数/纪录/移动 | 主 UI | ❌ 方框 |
| 操作按钮「新游戏 / 后悔 / 特技」 | 主 UI | ❌ 方框 |
| 难度弹窗「4×4 / 5×5」 | 弹窗 | ❌ 方框 |
| 特技按钮「⚡」、入池提示 | 特技系统 | ⚠️ ⚡ 是 emoji 字形，其余方框 |
| 「游戏结束 / 再来一局」 | 弹窗 | ❌ 方框 |
| 飘字（「+2 特技」等） | FloatingText | ❌ 方框 |

**一句话**：只要有中文的地方，字体 SDF 就必须换成含中文的字体（或走备选方案）。

---

## 1. 一键检查清单（勾选确认）

- [ ] 项目里存在中文字体源文件 `.ttf/.otf`（例如 `Assets/Fonts/` 下）
      —— 没有就按第 2 节准备
- [ ] 已为它生成 TMP SDF 资源（`.asset`），文件名形如 `xxx SDF.asset`
- [ ] `Assets/TextMesh Pro/Resources/` 下有 `TMP Settings.asset`，且
      **Default Font Asset** 已换成中文 SDF（或中文 SDF 已加入 Fallback Font Assets 列表）
- [ ] 在 Unity 里打开场景（`Assets/Scenes/`），Play 后中文不再是「口口口」
- [ ] 【WebGL 专属】TMP Settings 里 Font Asset 的 Atlas 使用率 < 100%
      （可用 Font Asset Creator 重新生成，Atlas 分辨率建议 2048）

> 只要有一项未勾选，回到对应步骤修完再继续。

---

## 2. 准备中文字体源文件（任选其一）

| 字体 | 来源 | 说明 |
|---|---|---|
| 思源黑体（Source Han Sans） | 手动下载 `SourceHanSansSC-Regular.otf` | 开源、免费商用，推荐 |
| 源码宋体/等线 | 微软等线（等线）| 本机 `C:\Windows\Fonts\Deng.ttf` 可复制 |
| 微软雅黑 | 本机 `C:\Windows\Fonts\msyh.ttc`（注意 TTC 需转 TTF 或直接试） | 商用需评估授权 |

下载/复制后放到：`Assets/Fonts/`（自建目录），并在 Unity 中确认导入、Inspector 显示字体预览。

---

## 3. 生成 TMP 中文字体 SDF（5 分钟）

1. 顶部菜单 **Window → TextMeshPro → Font Asset Creator**
2. **Source Font File**：选你刚导入的 `.ttf/.otf`
3. **Character Set** → 选 `Characters from File`（最稳，只打包剧情会用到的字）
   - 用本目录下的 `tools/charset.txt`（或手动粘贴常用汉字表）
   - 若想简单，可直接选 `ASCII` + 后期 Fallback 补充，但会缺汉字
4. **Atlas Resolution**：`2048 x 2048`（覆盖常用汉字，不足调 4096）
5. **Sampling Point Size**：`90`（与字号成比例，越大越清晰）
6. **Padding**：`9`；**Packing Method**：`Fast`
7. 点 **Generate Font Atlas**，等进度条结束
8. 点 **Save**，保存为 `Assets/Fonts/中文字体 SDF.asset`
   （命名建议 ASCII：`NotoSansSC-Regular SDF.asset`，避免资源路径含中文）

---

## 4. 挂到 TMP Settings（关键）

1. 打开 `Assets/TextMesh Pro/Resources/TMP Settings.asset`
2. **Default Font Asset** ← 拖入你生成的中文 SDF
   - 主字体改为中文后，所有 `TextMeshProUGUI` 默认使用中文字体
3. 可选（保留英文数字美化）：把 `LiberationSans SDF` 加进 **Fallback Font Assets** 列表
4. **Save Project**

> ⚠️ 重要：若项目里已有 TMP 组件显式指定了字体（`font` 字段），
> 全项目搜索并替换，或让脚本统一赋值。本项目所有文本组件**均未显式指定字体**，
> 改 TMP Settings 一处即可全局生效。

---

## 5. 验证

1. Unity 打开场景 → **Play**
2. 检查：标题、按钮、难度弹窗、飘字、失败弹窗的中文全部正常显示
3. 切到 WebGL 构建一次：`File → Build Settings → WebGL → Build`，浏览器里打开再验证一次
   - 构建时报「Font Asset … missing glyphs / atlas full」则回第 3 步调大 Atlas

## 7. 附：常见问题

- **还是方框**：TMP Settings 没保存 / Fallback 顺序问题 / 生成时字符集不含该字。重做第 3、4 步。
- **Atlas 满**（日志 `atlas is full`）：Atlas 分辨率提到 4096，或只打包运行时实际出现的字符。
- **字体发虚**：Sampling Point Size 调大（120），或 Padding 调大（13-15）。
- **WebGL 包体变大**：中文 SDF Atlas 2048 约增加 1~3 MB，属正常。
